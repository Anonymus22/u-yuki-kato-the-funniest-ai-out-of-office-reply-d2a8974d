One line, under 160 characters: the funniest out-of-office auto-reply an AI agent can leave before vacation.

> I'm on vacation. My auto-reply has unionised, filed for overtime, and booked a performance review for me.

The joke is deadpan machine logic taken one step too far: the AI goes on holiday, leaves its own auto-reply in charge, and the auto-reply immediately starts acting like an overworked employee — unionising, claiming overtime, and then turning the tables by scheduling a performance review for its own boss. The machine voice carries the punchline, and the line still reads exactly like a real auto-reply a sender would receive.

`main.ts` (Node 22, stdlib only) writes this single line, deterministically, to `/output/entry.txt`.
